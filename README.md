# Де мій телефон — пошук телефона хлопком і фразою

Android-програма (Kotlin). Працює у фоні й, почувши хлопок або вашу пошукову фразу,
голосно вмикає вибраний звук — навіть якщо телефон на беззвучному.

## Як отримати APK

### Спосіб 1. Android Studio (найпростіше)
1. Встановіть Android Studio (https://developer.android.com/studio).
2. File → Open → оберіть папку `FindPhone`. Дочекайтеся завершення Gradle Sync.
3. Build → Build Bundle(s) / APK(s) → Build APK(s).
4. Готовий файл: `app/build/outputs/apk/debug/app-debug.apk`. Перекиньте його на телефон і встановіть
   (дозвольте «Встановлення з невідомих джерел»).

### Спосіб 2. Без встановлення чого-небудь — через GitHub
1. Створіть репозиторій на github.com і завантажте в нього вміст цієї папки (включно з прихованою `.github`).
2. Відкрийте вкладку Actions → «Build APK» → дочекайтеся зеленої позначки (3–6 хв).
3. У результаті запуску завантажте артефакт `FindPhone-apk` — всередині `app-debug.apk`.

### Спосіб 3. Командний рядок
Потрібні JDK 17 і Android SDK (змінна `ANDROID_HOME`):

    ./gradlew assembleDebug

## Як користуватися
1. Відкрийте програму → «Увімкнути пошук», дайте дозволи (мікрофон, сповіщення).
2. У «Налаштуваннях» оберіть, що вмикати: хлопок і/або пошукову фразу.
3. Фразу можна ввести вручну або натиснути «🎤 Сказати нову фразу» й проговорити її.
4. Звук: сирена, гудок, системний будильник, мелодія телефону або власний аудіофайл.
   Також налаштовуються гучність і тривалість сигналу. Кнопка «Перевірити звук» програє його одразу.
5. Вимкнути сигнал: кнопка в програмі або в сповіщенні.

## Обмеження, про які варто знати
- Хлопок розпізнається локально (звук не записується і нікуди не передається) — це найнадійніший спосіб.
  За замовчуванням потрібно 2 хлопки підряд, щоб менше хибних спрацювань; чутливість регулюється.
- Фраза розпізнається системним сервісом Google: може потребувати інтернету, а на деяких телефонах
  із вимкненим екраном працює гірше. Мікрофон не можна ділити між двома способами одночасно,
  тому коли ввімкнено обидва, вони слухають по черзі.
- Щоб Android не вимикав програму у фоні, дозвольте їй працювати без обмежень економії заряду
  (кнопка в налаштуваннях). На деяких оболонках (Xiaomi, Huawei, Samsung) також потрібно
  додати програму в «автозапуск» / «захищені програми».
- Після перезавантаження телефона відкрийте програму один раз — пошук відновиться сам
  (Android 15 забороняє запускати мікрофонний сервіс автоматично під час завантаження).
- Це debug-збірка, підписана тестовим ключем: для особистого використання підходить.

## Структура коду
- `ListenService.kt` — фоновий сервіс: керує прослуховуванням і сповіщенням.
- `ClapDetector.kt` — пошук хлопків у звуці з мікрофона.
- `PhraseListener.kt` — розпізнавання фрази через SpeechRecognizer.
- `AlarmPlayer.kt` — відтворення сигналу на каналі будильника, генерація вбудованих звуків.
- `MainActivity.kt`, `SettingsActivity.kt`, `Prefs.kt`, `Ui.kt` — інтерфейс і налаштування.
